# Selenium Java Web Automation

A Maven-based browser automation project built with **Java** and **Selenium WebDriver** in VS Code. This project demonstrates automated browser navigation, element location, form filling, explicit waits, and login flows across web practice platforms.

## Tech Stack

* **Language:** Java (JDK 24)
* **Build Tool:** Apache Maven
* **Automation Framework:** Selenium WebDriver (`4.27.0`)
* **Testing Library:** JUnit (`4.13.2`)
* **Browser Driver:** Google Chrome / ChromeDriver (managed automatically via Selenium Manager)
* **IDE:** Visual Studio Code
